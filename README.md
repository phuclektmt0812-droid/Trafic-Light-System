# CO3009 - Two-Road Traffic Light System

## Course Information
- Course: CO3009 - Microprocessors and Microcontrollers
- Semester: 1 - Academic Year 2026-2027
- Microcontroller: STM32F103RB
- Development Board: XNUCLEO-F103RB

## Project Description
A two-road traffic light control system with:
- Automatic Mode
- Manual Mode
- Timing Adjustment Mode
- Temperature and Humidity Display using DHT20
- LCD Display
- O(1) Task Scheduler

## Hardware
- XNUCLEO-F103RB
- Traffic Light Modules
- Push Buttons
- DHT20 Sensor
- LCD Display

## Software
- STM32CubeIDE
- STM32 HAL Library
- C Programming Language
